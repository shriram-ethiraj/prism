# Your wallpapers

Put JPEG, PNG or WebP images in this folder, then run `npm run build`.

Prism creates a display image, a thumbnail, matching frosted material and an adaptive color palette. The images appear under the **Settings → Wallpaper** gallery.

Use landscape images; 3840×2160 or larger gives the best source detail. Images are cover-cropped and orientation is corrected. Filenames become friendly titles. Original files stay untouched.

Personal images and generated output are ignored by Git by default. No upload service or online provider is required.
