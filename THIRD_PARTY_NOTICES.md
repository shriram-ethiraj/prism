Source references and retained notices are in `public/preview-icons/SOURCES.md` and `BRAND-ARTWORK-LICENSE.txt`. Captured monitor tiles and the Google Play icon are not distributed. Native mode resolves artwork from installed applications.
- **Deployment**: setup includes transport/signing/certificate primitives from AeroTizen (MIT, Hamza El Alaoui), pinned at `029b2a97d00e63c25328ddc151da32d4476e06ff`. The transport/signing implementation also acknowledges MIT TizenSdb.Core; the certificate flow acknowledges MIT Apps2Samsung. Private signing material is never included here.

The on-monitor app has no external runtime dependencies. Build and test dependencies retain their package licenses.

## Standalone installer dependencies

Standalone archives include the Python runtime, cryptography/cffi/pycparser, certifi, and PyInstaller runtime components. Their upstream license notices are included in the archive's `_internal/licenses` directory; Linux archives also retain distro copyright notices and referenced GNU license texts for bundled shared libraries. Build-only dependencies and platform packaging libraries are pinned in `requirements-installer.txt`. Existing Samsung trust-anchor and vendored-code provenance remains unchanged; no private signing identity is distributed.
